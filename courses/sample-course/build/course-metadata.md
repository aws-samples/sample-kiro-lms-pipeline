# Course Metadata

Course-level metadata for LMS upload, prepared per Step 4 of `course-planning.md`.
The SCORM zip is the training; this file holds the fields you paste into the LMS upload form.

## Title

Build a SCORM Course from Markdown

## Description

This course shows course authors how the markdown-to-SCORM pipeline in this repository turns authored lessons into an LMS-ready package.

By the end, you will be able to:

- Trace how `course.yaml` and per-module `lesson.md` files become a single-page SCORM 1.2 package
- Author ungraded and graded knowledge checks with per-option feedback
- Embed images from a module's `visuals/` folder and control page-dwell gating
- Explain how automatic completion and the mastery score are reported to the LMS

No prerequisites beyond basic familiarity with Markdown.
